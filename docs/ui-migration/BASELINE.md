### Drift / Discrepancies Found Since Inventory

1. **Filename drift in `docs/`:** On disk, the approved BCR spec is `docs/BACKEND_CHANGE_REQUESTS.md` (underscores) rather than `docs/BACKEND-CHANGE-REQUESTS.md` (hyphens). `docs/BACKEND-IMPLEMENTATION-PROMPTS.md` and `docs/UI-MIGRATION-PROMPTS.md` are not stored in `docs/` (prompts are delivered turn-by-turn).
2. **Baseline build & typecheck failure caused by commits `ee959d5` + `9d052b8` (not fixed silently per rule):**
    - Commit `ee959d5` commented out `Features::emailVerification()` in `config/fortify.php`. Because `resources/js/routes/**` is git-ignored and regenerated by `@laravel/vite-plugin-wayfinder`, the `verification` route module (`@/routes/verification`) is no longer generated when `Features::emailVerification()` is disabled. However, `resources/js/pages/auth/verify-email.tsx` (line 7) still contains `import { send } from '@/routes/verification';`, which causes both `npm run build` (`rolldown`) and `npm run types:check` (`tsc --noEmit`) to fail on `resources/js/pages/auth/verify-email.tsx:7:22`. (This will automatically resolve when `BE-12` re-enables `Features::emailVerification()`.)
    - Commit `9d052b8` added `frontend/**` (48 files), which is not yet in `vite.config.ts` `lint.ignorePatterns` / `fmt.ignorePatterns` (scheduled for `UI-02`), causing `npm run check` (`vp check`) to lint and format-check `frontend/**`.
3. **`MessageController@index` unread state nuance:** `MessageController@index` marks all incoming messages read _before_ querying `$messages`, meaning `isUnread` in the returned prop array is always `false` unless `BE-05` captures unread state prior to marking read (or defers marking read to the existing `POST portal/messages/read` endpoint).
